## ⚡ Проблема: отвал буфера обмена в Illustrator при активной работе

При продолжительной и активной работе в Adobe Illustrator (особенно на Windows 10/11) пользователи регулярно сталкиваются с отказом буфера обмена:

1. **Тихий сбой:** Выделяется векторный объект, нажимается `Ctrl+C` (или *Редактирование ➔ Скопировать*). Визуально никаких ошибок не появляется.
2. **Вставка не работает:** При нажатии `Ctrl+V` (или *Вставить на то же место*) ничего не происходит, либо вставляется старое содержимое, скопированное до сбоя.
3. **Сбой сохраняется в новых макетах:** Нажатие `Ctrl+C` даже на обычном прямоугольнике в чистом новом документе (`Ctrl+N`) не работает.
4. **Потеря рабочего времени:** Единственным решением оставался принудительный перезапуск `Illustrator.exe` со сбросом истории отмен.

## 🔬 Диагностический аудит: как была выявлена причина сбоя

Для точной локализации проблемы была разработана низкоуровневая диагностическая утилита — **[AI-ClipboardDoctor](tools/AI-ClipboardDoctor/)**, отслеживающая системные события Windows API в реальном времени.

```text
================================================================================
  СОБЫТИЕ #5 — [CTRL+C] — INFO
  Время: 23:44:53.731 | Процесс: Illustrator (PID: 57224)
  GDI Handles: 2 292 | User Handles: 4 545
  Состояние: Ожидание публикации данных Windows Clipboard (Ревизия: #5545).
================================================================================

================================================================================
  СОБЫТИЕ #6 — [WARN: NO VECTORS] — WARNING
  Время: 23:44:53.802 | Задержка: 71 мс
  Сводка: ВНИМАНИЕ: Векторные форматы отсутствуют в буфере обмена!
  Владелец буфера: Illustrator (PID: 57224)
  Заблокирован:    НЕТ (Буфер свободен)
  Ревизия буфера:  Sequence #5546
  Всего форматов:  0
  Общий объём:     0.0 КБ
  Форматы:         [ПУСТО — 0 форматов]
================================================================================
```

### Технические выводы аудита:
* **Дескрипторы GDI и User в норме:** 2 292 GDI и 4 545 User дескрипторов (значительно ниже лимита Windows в 10 000). Утечки дескрипторов ОС нет.
* **Блокировок буфера сторонними программами нет:** Буфер обмена не захвачен внешними приложениями (браузерами, мессенджерами или менеджерами буфера). Владельцем является исключительно `Illustrator.exe`.
* **Локализация сбоя:** При нажатии `Ctrl+C` Illustrator вызывает API-функции `OpenClipboard()` и `EmptyClipboard()`, инкрементируя системный счётчик буфера (`#5545 ➔ #5546`). Однако во время внутренней сериализации геометрии в стандартные векторные форматы обмена (`AICB`, `Adobe Illustrator Private Format`, `PDF`) внутри собственного сериализатора Illustrator происходит критический сбой. Illustrator аварийно вызывает `CloseClipboard()`, оставляя системный буфер **абсолютно пустым (0 форматов, 0.0 КБ)**.
* **Подсистема вставки (Paste Engine) исправна:** При инъекции тестового векторного потока `AICB` напрямую в буфер через `AI-ClipboardDoctor`, нажатие `Ctrl+V` в Illustrator мгновенно и безошибочно вставляет тестовый вектор.
* **Вывод:** Проблема изолирована строго во **внутреннем модуле сериализации копирования Illustrator** (процессный синглтон), который после сбоя не может восстановиться без перезапуска процесса.

*(Полный текст технического отчёта доступен в файле [`tools/AI-ClipboardDoctor/illustrator_clipboard_failure_analysis.md`](tools/AI-ClipboardDoctor/illustrator_clipboard_failure_analysis.md)).*

* **🔥 Горячие клавиши работают из коробки:**
  - `F5` — мгновенно скопировать выделение во внутренний изолированный буфер памяти.
  - `F6` — вставить на то же место (*In Place*).
  - `F7` — вставить точно по центру текущего экрана (*Center of View*).
  - `F8` — размножить сразу на все артборды макета (*Paste on All Artboards*).
  - `F9` — быстрое зеркальное отражение по вертикали (*Reflect Vertical*, $x = cx$).
  - `F10` — быстрое зеркальное отражение по горизонтали (*Reflect Horizontal*, $y = cy$).
  - `Ctrl + Numpad [1..9]` — клонирование со смещением ровно на размер объекта (*Pattern Offset Clone*).
  - `Alt + Numpad [1..9]` — сдвиг выделения без дублирования на размер объекта (*Pattern Offset Move*).
  - `Ctrl + Alt + [1..9]` — мгновенная установка кратности шага от $1/1$ до $1/9$ (*Step Divisor*).
  Плагин перехватывает нажатия глобально на уровне процесса без необходимости кликать мышью по палитре или переключать фокус!

* **🎯 Скоростное создание узоров, пиксель-арта и паттернов (Вкладка «Offset Clone»):**
  - **Проблема классического Illustrator:** Чтобы размножить плитку, модуль или элемент узора со смещением ровно на его ширину или высоту, дизайнеру приходилось каждый раз открывать окно `Object ➔ Transform ➔ Move...` (`Shift+Ctrl+M`), смотреть или высчитывать размеры в точках/пикселях, вручную вбивать значения `Horizontal`/`Vertical`, нажимать `Copy`, затем `Ctrl+D`. Это отнимало много времени, сбивало творческий ритм и утомляло при сборке изометрии, бесшовных паттернов и пиксельной векторной графики.
  - **Решение в плагине:** Плагин в реальном времени замеряет габариты выделенного объекта (`Selection: W x H pt`). Зажмите **`Ctrl`** и нажимайте клавиши стрелок или цифрового кейпада **`1..9`** (или кликайте по 3x3 матрице на панели) — объект моментально дублируется стык-в-стык ровно на свой точный габарит в выбранном направлении (включая 4 диагональных угла: `7` — влево-вверх, `9` — вправо-вверх, `1` — влево-вниз, `3` — вправо-вниз).
  - **Рисование узоров «на лету»:** Удерживая клавишу или быстро нажимая комбинацию (например, `Ctrl+Num6`, `Ctrl+Num6`, `Ctrl+Num2`), вы выстраиваете непрерывные ряды плитки, геометрические орнаменты, кирпичные кладки или изометрические пиксельные иллюстрации за секунды — со скоростью пиксельной кисти, но в чистом редактируемом векторе!
  - **Режим перемещения (`Alt`):** Если требуется сдвинуть объект без создания дубликата, зажмите **`Alt + [1..9]`** — объект сделает дискретный шаг на свой размер, сохраняя выделение.
  - **Специально для ноутбуков:** Если у вас клавиатура без отдельного блока Numpad, в настройках (`Settings...`) можно в один клик переключиться на стандартный верхний ряд цифр `1..9`, раскладку букв `QWE / ASD / ZXC`, `UIO / JKL / M` или настроить любые удобные клавиши.

* **📐 Дробный шаг смещения «Step Divisor» ($1/N$):**
  - **Работа со сложными составными блоками:** Часто требуется размножить не одиночный объект, а сложную цепочку или группу (например, диагональный паттерн из 6 квадратов). Стандартный сдвиг сместил бы всю группу на её 100% габарит.
  - **Быстрое задание кратности:** Нажатием **`Ctrl + Alt + [1..9]`** (или кликом по кнопке `[ Step: 1/N ]` на панели) вы задаете делитель шага $\Delta = \frac{\text{Размер}}{N}$. При шаге `1/6` весь блок из 6 элементов сдвигается или дублируется ровно на ширину одной ячейки!
  - **Динамическая иконка палитры:** Иконка свернутой панели в доке Illustrator автоматически показывает зеленую цифру текущего шага ($1..9$).
  - **Информационная строка:** Отображает точный вычисленный шаг: `Sel: W x H | Step 1/6: (W/6) x (H/6) pt`.

* **🪞 Мгновенное отражение по хоткеям (Reflect Vertical / Horizontal):**
  - Клавиши `F9` (Reflect Vertical, зеркалирование лево/право) и `F10` (Reflect Horizontal, зеркалирование верх/низ) отражают выделенные объекты относительно их геометрического центра.
  - Больше не нужно выбирать инструмент `Reflect Tool (O)` на панели инструментов или заходить в контекстные диалоги. В связке с Offset Clone это позволяет мгновенно генерировать зеркально-симметричные орнаменты и розетки.

* **🛡️ Исправление критического бага стабильности (Crash Fix):**
  - Устранена ошибка, приводившая к падению Illustrator при копировании и вставке сложных векторных объектов (составных контуров / Compound Paths, обтравочных масок / Clipping Masks, сгруппированных объектов с эффектами оформления).
  - *Причина сбоя:* Ранее при включенной опции автовыделения после вставки флаги выделения рекурсивно накладывались на внутренние подконтуры составных путей, что нарушало целостность графа объектов в памяти и вызывало падение встроенного модуля `StrokeOffset.aip` при последующей перерисовке (`RedrawDocument`).
  - *Исправление:* Выделение теперь устанавливается строго по стандартам Adobe SDK на верхний уровень контейнеров, а контекст `CopyScope` изолирован, гарантируя полную стабильность на самых тяжёлых макетах.

* **🎨 Нативное оформление и поддержка всех тем:** Палитра повторяет дизайн стандартных кнопок палитры *Свойства (Properties)* со скруглением 3px и автоматически перерисовывается под текущую тему Illustrator (тёмная, средне-тёмная, средне-светлая, светлая).
* **⚙️ Графический диалог настроек (7 разделов):** Кнопка **Settings...** открывает окно переназначения любых клавиш (`F1`–`F12`, `Alt+...`, `Ctrl+...`, `Ctrl+Alt+...`), выбор пресета матрицы смещения, раздельный выбор модификаторов для Clone/Move/Step, включение/отключение плагина и опцию автовыделения объектов (*Select object(s) after paste*).

## ⌨️ Настройка глобальных горячих клавиш (F5 / F6 / F7)

Сторонние расширения Adobe CEP не могут перехватывать системные нажатия клавиш без активного фокуса на панели. Проблема решена регистрацией трёх команд меню Illustrator:
* `CP_copy`
* `CP_place`
* `CP_paste`

Связав их с операциями (Actions), пользователь получает **настоящие глобальные горячие клавиши**, работающие из любого места макета!

### Способ 1: Загрузка готового набора операций (Рекомендуется)
1. В Illustrator откройте палитру операций: `Окно` ➔ `Операции` (`Window` ➔ `Actions`).
2. В меню палитры выберите пункт **«Загрузить операции...»** (**Load Actions...**).
3. Выберите файл из каталога плагина:

## 📦 Установка

### Автоматическая установка (Windows — Рекомендуется)
1. Скачайте свежий релиз: [`Clipboard_Paste_v1.0.12.zip`](https://github.com/SaidAuita/AI-Clipboard-Paste/releases/latest).
2. Закройте Adobe Illustrator.
3. Запустите файл `Install.bat` двойным кликом.
   * Скрипт пропишет режим отладки Adobe CEP (`PlayerDebugMode`) в системном реестре Windows;
   * Очистит устаревший кэш CEP;
   * Безопасно скопирует расширение в `%APPDATA%\Adobe\CEP\extensions\Clipboard Paste\`.
4. Запустите Illustrator и откройте панель:  
   `Окно` ➔ `Расширения` ➔ **`Clipboard Paste`** (или микро-панели `CP_copy`, `CP_place`, `CP_paste`).

### Ручная установка (macOS & Windows)
1. Скопируйте папку расширения в системный каталог CEP:
   * **Windows:** `%APPDATA%\Adobe\CEP\extensions\Clipboard Paste\`
   * **macOS:** `~/Library/Application Support/Adobe/CEP/extensions/Clipboard Paste/`
2. Включите режим отладки `PlayerDebugMode`:
   * **Windows:** запустите `enable_player_debug_mode.reg`.
   * **macOS:** выполните в Терминале:
     ```bash
     defaults write com.adobe.CSXS.11 PlayerDebugMode 1
     defaults write com.adobe.CSXS.12 PlayerDebugMode 1
     defaults write com.adobe.CSXS.13 PlayerDebugMode 1
     defaults write com.adobe.CSXS.14 PlayerDebugMode 1
     ```
3. Перезапустите Illustrator.

### Удаление
Для полного удаления запустите `Uninstall.bat`. Настройки и экшены Illustrator не будут затронуты.

## 🛠 Технические подробности для разработчиков

* **ExtendScript Shared Engine:** Все панели подключаются к общему глобальному движку `#targetengine "CP_SHARED"`. Данные, скопированные через микро-панель `CP_copy`, мгновенно видны в главной панели и панелях вставки без межпроцессных задержек.
* **Тройное резервирование буфера:**  
  1. `$.global.ClipboardPasteHost`
  2. Резервная копия `app.__CP_BUFFER__`
  3. Структурированный дескриптор геометрии (координаты, границы артборда, иерархия слоёв).
* **Hot Reload:** Клик по бейджу версии `v1.0.12` в шапке панели или правый клик по микро-панелям перезагружает интерфейс и скрипты на лету.
