# Clipboard Paste — Нативный C++ плагин (.aip)

<p align="center">
  <a href="README.md"><b>🇬🇧 Read in English</b></a>
</p>

Высокоскоростной нативный C++ плагин дублирования векторных объектов для **Adobe Illustrator CC 2020 – 2026+**.

## 🚀 Ключевые преимущества перед CEP-расширением
- **Глобальные горячие клавиши из коробки:** Настраиваемые хоткеи (`F5`, `F6`, `F7` или любые пользовательские сочетания) работают сразу после установки через низкоуровневый хук сообщений Windows (`WH_GETMESSAGE`). Не нужно кликать по панели или переключать фокус.
- **Никаких всплывающих окон и морганий экрана:** В отличие от CEP-версии, которой для срабатывания хоткеев требовалось на доли секунды открывать вспомогательные HTML-микропанели, нативный плагин работает полностью бесшумно внутри процесса `Illustrator.exe` без визуальных артефактов.
- **Пиксель-в-пиксель нативный интерфейс:** Полностью кастомная докируемая палитра в стиле Adobe Spectrum со скруглением кнопок 3px (поддерживает как тёмные, так и светлые темы интерфейса с автоматической перерисовкой при смене темы).
- **Прямое выполнение в памяти процесса:** Глубокое дублирование геометрии (`sAIArt->DuplicateArt`) занимает менее 1 мс без прохождения через медленный и сбойный системный OLE-буфер Windows.

## 📁 Структура каталогов
```
native-plugin/
├── src/                      # Исходный код C++17
│   ├── PluginMain.cpp        # Точка входа SweetPea
│   ├── ClipboardPastePlugin  # Жизненный цикл панели, отрисовка UI, обработка событий
│   ├── BufferManager         # Движок векторного дублирования (sAIArt)
│   ├── ConfigManager         # Сохранение настроек горячих клавиш (Win32 INI)
│   └── Suites                # Указатели на Suite интерфейсы Illustrator SDK
├── resources/                # Ресурсы Windows (.rc, .pipl, SVG иконки)
├── build.bat                 # Скрипт компиляции MSVC x64
├── build_dev.js              # Скрипт сборки dev-пакета (формирует версионированный zip)
├── Install_Plugin.bat        # Автоматический инсталлятор (детектирует AI 2020..2026+)
├── Uninstall_Plugin.bat      # Деинсталлятор
└── ClipboardPaste.aip        # Предсобранный 64-битный бинарник
```

## 🛠️ Сборка из исходников
### Требования
- **Windows 10 / 11 x64**
- **Microsoft Visual Studio 2022** (с компонентом «Разработка классических приложений на C++»)
- **Adobe Illustrator SDK** (CC 2020 или новее)

### Шаги сборки
1. Задайте переменную окружения `ILLUSTRATOR_SDK` с путем к SDK (опционально, если структура каталогов по умолчанию):
   ```cmd
   set ILLUSTRATOR_SDK=C:\path\to\Adobe Illustrator 2026 SDK
   ```
2. Запустите `build.bat` в командной строке:
   ```cmd
   build.bat
   ```
3. Скомпилированный плагин появится по пути `build\x64\ClipboardPaste.aip`.

## 📦 Установка
Запустите `Install_Plugin.bat` от имени администратора. Скрипт автоматически найдет все установленные версии Adobe Illustrator (2020–2026+) и скопирует `ClipboardPaste.aip` в системную папку `Plug-ins`.
