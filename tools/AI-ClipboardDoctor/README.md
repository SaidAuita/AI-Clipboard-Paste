# AI-ClipboardDoctor: Диагностический Sentinel

## Цель проекта
Разработка диагностической утилиты для Windows 11, предназначенной для выявления и анализа причин зависания механизма копирования векторных объектов из Adobe Illustrator (версия 30.8.2+) в буфер обмена Windows.

### Основные задачи:
- **Пассивный мониторинг**: Отслеживание событий изменения буфера обмена при активном Illustrator без перехвата содержимого документов.
- **Диагностика**: Фиксация доступности форматов данных (CF_UNICODETEXT, форматы Adobe и др.) в моменты сбоя копирования.
- **Журналирование**: Сбор метаданных (время, PID Illustrator, GDI/User handles, успешность записи в буфер) для последующего анализа причин (незапись данных Illustrator'ом, блокировка Windows, или ошибки парсинга).
- **Экспорт**: Возможность выгрузки логов для анализа и передачи в Adobe Support.

---
*Проект создан для борьбы с известным дефектом Illustrator, при котором копирование векторных объектов перестает работать после продолжительной сессии работы.*

## Инструкция по использованию

1. **Запуск**: Запустите `AI-ClipboardDoctor.exe`. Приложение запустится в системном трее и начнет пассивный мониторинг буфера обмена.
2. **Мониторинг**: В случае сбоя копирования в Illustrator, откройте окно программы (двойной клик по иконке в трее).
3. **Диагностика**:
   - В списке событий будут отображены попытки копирования. Красным цветом выделены ошибки (Failure).
   - Если Illustrator перестал вставлять объекты:
     - Нажмите **"Test Vector Inject"** (⚡): если Illustrator вставит тестовую звезду, значит, проблема в его собственном движке копирования.
     - Нажмите **"Reset & Unlock Clipboard"** (🔓): это попытается освободить зависшие блокировки буфера обмена.
4. **Отчетность**: Если проблема сохраняется, используйте кнопку **"Export Report"** (💾) для создания файла отчета (JSON или CSV), который можно приложить к баг-репорту в Adobe Support.
