# Анализ и формализация сбоя копирования векторов в Adobe Illustrator 2026 (v30.8.2)

- **Дата фиксации:** 2026-10-28
- **Версия Illustrator:** Adobe Illustrator 30.8.2 (64-bit)
- **Операционная система:** Windows 11 (build 10.0.19041+)
- **Утилита диагностики:** AI-ClipboardDoctor Sentinel v1.0.2

---

## 1. Симптоматика проблемы

1. **Поведение в интерфейсе Illustrator:**
   - Пользователь выделяет векторный объект (или группу объектов) в рабочем макете Illustrator.
   - Нажимает сочетание клавиш `Ctrl+C` (или выбирает *Edit -> Copy*).
   - Визуально никаких ошибок не появляется.
   - При попытке вставить скопированный объект (`Ctrl+V` или *Edit -> Paste*) вставка не происходит, либо вставляется содержимое, которое находилось в буфере до этого (текст, скриншот и т.д.).
   - Повторные нажатия `Ctrl+C` даже на простейших фигурах (прямоугольник, круг) и в новом чистом документе (`Ctrl+N`) проблему не решают.

## 3. Технический диагноз и локализация сбоя

### 3.1. Что происходит на уровне Windows API и OLE:
1. При нажатии `Ctrl+C` Illustrator вызывает стандартную процедуру публикации в буфер обмена Windows:
   - `OpenClipboard(hWnd)`
   - `EmptyClipboard()` — очищает старые данные. При этом системный счетчик буфера инкрементируется (`Sequence #5545 -> #5546`).
2. Далее Illustrator должен запустить сериализацию выделенной векторной геометрии в стандартные векторные форматы обмена:
   - `Adobe Illustrator Private Format`
   - `AICB` (Adobe Illustrator Clipboard format)
   - `PDF` (`Portable Document Format`)
   - `CF_ENHMETAFILE` (`EMF`)
   - `SVG` / `HTML Format`
3. **Место сбоя:**  
   Внутри модуля OLE/векторной сериализации Illustrator происходит критический внутренний сбой (необработанное исключение / повреждение внутреннего состояния OLE-сервера Illustrator).  
   Вместо публикации данных Illustrator досрочно вызывает `CloseClipboard()`, **оставляя буфер обмена абсолютно пустым (0 байт, 0 форматов)**.

### 3.2. Локализация (Copy vs. Paste):
- **Подсистема вставки (Paste Engine) исправна:**  
  При синтетической инъекции векторного контура (формат `AICB` с PostScript-потоком `%Creator: AI-ClipboardDoctor`) через кнопку *«Тест вставки»* нажатие `Ctrl+V` в Illustrator мгновенно и корректно вставляет тестовую фигуру (звезду).
- **Следовательно:**  
  Проблема локализована **строго в блоке копирования/сериализации (Copy / Serialization Engine)** Adobe Illustrator.

### 3.3. Анализ дескрипторов и ресурсов процесса:
- **GDI Handles:** 2292 из 10 000 (норма для стабильной работы < 7000). Лимит дескрипторов GDI не превышен.
- **User Handles:** 4545 из 10 000. Лимит также не превышен.
- **Блокировки буфера (Clipboard Lock):** Отсутствуют. Буфер свободен, захвата сторонними приложениями (сторонними утилитами, мессенджерами) нет. Владельцем является сам Illustrator.

## 4. Почему сбой сохраняется в новых документах (`Ctrl+N`)

Векторный OLE-сериализатор Illustrator инициализируется как часть общего синглтон-модуля при запуске приложения.  
Когда внутренняя структура сериализатора повреждается (например, при попытке сериализовать объект со специфическим градиентом, эффектом, поврежденным шрифтом или неограниченной прозрачностью), модуль переходит в состояние ошибки (unhandled fault).  
Открытие нового документа не перезапускает DLL-модули Illustrator в памяти, поэтому все последующие операции `Ctrl+C` продолжают завершаться пустым буфером (`0 formats`).

## 5. Методы решения и порядок действий

### А. Для пользователя (Немедленное восстановление работы):
1. **Сохранить все макеты:**  
   Нажать `Ctrl+S` или *File -> Save As* во всех открытых вкладках. (Функция сохранения файлов работает независимо от буфера обмена).
2. **Перезапустить Adobe Illustrator:**  
   Полностью закрыть Illustrator (проверить в Диспетчере задач отсутствие зависшего процесса `Illustrator.exe`) и запустить его заново.
3. **Проверить копирование в новом сеансе:**  
   После перезапуска внутренний OLE-сериализатор инициализируется с чистого листа, и `Ctrl+C` начинает работать штатно.

### Б. Профилактика в рамках проекта AI-ClipboardDoctor:
- Приложение `AI-ClipboardDoctor Sentinel` отслеживает состояние буфера в реальном времени.
- При фиксации события `[WARN: NO VECTORS]` утилита:
  - Выдает звуковое/всплывающее предупреждение пользователю о том, что копирование не удалось, предотвращая потерю времени на попытки вставки.
  - Позволяет в один клик экспортировать файл аудита (`.txt`, `.json`, `.csv`) для отправки в службу технической поддержки Adobe.
  - Предоставляет кнопку `[ 🔓 СБРОС БУФЕРА ]` для принудительной разблокировки буфера, если он остался захвачен зависшим процессом.
