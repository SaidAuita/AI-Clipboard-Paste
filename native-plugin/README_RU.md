## 🚀 Ключевые возможности и преимущества
- **🎯 Быстрое создание узоров, пиксель-арта и паттернов (Вкладка «Offset Clone»):**
  - Мгновенное дублирование выделенного объекта стык-в-стык ровно на его размер по горячим клавишам `Ctrl + [1..9]` (или сдвиг без дублирования по `Alt + [1..9]`).
  - Полный отказ от медленного диалога `Move...` (`Shift+Ctrl+M`): не нужно высчитывать размеры и вводить координаты вручную. Паттерны и изометрия собираются за секунды!
  - Поддержка пресетов для ноутбуков без Numpad: верхний цифровой ряд `1..9`, буквенные матрицы `QWE/ASD/ZXC`, `UIO/JKL/M` или пользовательские клавиши.
- **🪞 Зеркальное отражение по хоткеям (`F9` / `F10`):**
  - `F9`: Reflect Vertical (зеркалирование лево/право относительно центра).
  - `F10`: Reflect Horizontal (зеркалирование верх/низ относительно центра).
- **Глобальные горячие клавиши буфера из коробки:** `F5` (Copy), `F6` (Paste In-Place), `F7` (Paste Center), `F8` (Paste on All Artboards). Работают глобально на уровне процесса Windows без необходимости активировать окно плагина.
- **🛡️ 100% стабильность на сложных объектах:** Исправлен сбой при вставке составных контуров (Compound Paths), обтравочных масок и групп со сложными стилями оформления (селекция накладывается корректно на родительские контейнеры, исключая конфликт с `StrokeOffset.aip`).
- **Опция отключения горячих клавиш:** В диалоге настроек (**Settings...**) доступен чекбокс `Disable plugin (ignore hotkeys)`, позволяющий временно отключить перехват клавиш.
- **Никаких всплывающих окон и морганий экрана:** Нативный C++ плагин работает полностью бесшумно внутри процесса `Illustrator.exe` без открытия вспомогательных окон.
- **Пиксель-в-пиксель нативный интерфейс:** Полностью кастомная докируемая палитра в стиле Adobe Spectrum со скруглением кнопок 3px (поддерживает как тёмные, так и светлые темы интерфейса).
- **Прямое выполнение в памяти процесса:** Глубокое дублирование геометрии (`sAIArt->DuplicateArt`) занимает менее 1 мс без прохождения через медленный системный OLE-буфер Windows.

## 📁 Структура каталогов
```
native-plugin/
├── src/                      # Исходный код C++17
│   ├── PluginMain.cpp        # Точка входа SweetPea
│   ├── ClipboardPastePlugin  # Жизненный цикл панели, отрисовка UI, обработка событий
│   ├── BufferManager         # Движок векторного дублирования (sAIArt)
│   ├── ConfigManager         # Сохранение настроек горячих клавиш (Win32 INI)
│   └── Suites                # Указатели на Suite интерфейсы Illustrator SDK
├── resources/                # Ресурсы Windows (.rc, .pipl, SVG иконки)
├── build.bat                 # Скрипт компиляции MSVC x64
├── build_dev.js              # Скрипт сборки dev-пакета (формирует версионированный zip)
├── Install_Plugin.bat        # Автоматический инсталлятор (детектирует AI 2020..2026+)
├── Uninstall_Plugin.bat      # Деинсталлятор
└── ClipboardPaste.aip        # Предсобранный 64-битный бинарник
```

## 🛠️ Сборка из исходников
### Требования
- **Windows 10 / 11 x64**
- **Microsoft Visual Studio 2022** (с компонентом «Разработка классических приложений на C++»)
- **Adobe Illustrator SDK** (CC 2020 или новее)

### Шаги сборки
1. Задайте переменную окружения `ILLUSTRATOR_SDK` с путем к SDK (опционально, если структура каталогов по умолчанию):
   ```cmd
   set ILLUSTRATOR_SDK=C:\path\to\Adobe Illustrator 2026 SDK
   ```
2. Запустите `build.bat` в командной строке:
   ```cmd
   build.bat
   ```
3. Скомпилированный плагин появится по пути `build\x64\ClipboardPaste.aip`.

## 📦 Установка
Запустите `Install_Plugin.bat` от имени администратора. Скрипт автоматически найдет все установленные версии Adobe Illustrator (2020–2026+) и скопирует `ClipboardPaste.aip` в системную папку `Plug-ins`.
