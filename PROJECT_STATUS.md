# PROJECT_STATUS: Clipboard Paste

## Цель проекта
Легковесное CEP-расширение для Adobe Illustrator, обеспечивающее мгновенное и надёжное дублирование векторных объектов без использования сломанного OLE-буфера обмена Windows:
1. Копирование выделения на другой слой в те же координаты (Paste in Place: Target Layer).
2. Копирование выделения в новый документ в те же координаты артборда (Paste in Place: New Document).
3. Двухшаговый независимый буфер сессии (Шаг А -> Шаг B) для свободного перемещения между любыми открытыми документами и слоями.
Поддержка глобальных горячих клавиш через экшены/сценарии и быстрых клавиш в панели.

## История версий
- **v1.0.0**: Первичная реализация CEP-панели и ядро переноса на слой/в новый документ.
- **v1.0.1**: Исправление ошибки ExtendScript JSON (`JSON is undefined`), перенос в другие документы, Hot Reload по клику на версию.
- **v1.0.2**: Двухшаговый буфер в оперативной памяти сессии ExtendScript, вкладки режимов с запоминанием в `localStorage`, автономные скрипты в `actions/`.
- **v1.0.3**: Полный набор dock-иконок палитры (`icons/`), выпадающий список 8 языков (i18n из AI Code Pro), ссылки в подвале по образцу AI Dimension, горячие клавиши `Ctrl+F5`, `Ctrl+F6`, `Ctrl+F7`, автоустановка в `Presets/Scripts/Clipboard Paste/`.
- **v1.0.4**: Иконка в шапке панели, динамическая загрузка набора экшенов на лету (паттерн StockMasterPro) в палитру Операций через `app.loadAction`, самоповышение прав (UAC Elevation) в `Install.bat` для установки скриптов в системное меню `File -> Scripts`, очистка кэша CEP.
- **v1.0.5**: Двусторонняя реактивная синхронизация буфера через `CSXSEvent` (`PlugPlugExternalObject`) и фоновый 1-секундный таймер в CEP, перевод буфера на `$.global.ClipboardPasteHost`.
- **v1.0.6**: Переход на полностью изолированную архитектуру без вмешательства в системные каталоги `Program Files` и `Presets`. Устранение `registerKeyEventsInterest`.
- **v1.0.7**: Поддержка 3 команд меню в `Window -> Extensions` (`Clipboard: Copy`, `Clipboard: Paste In Place`, `Clipboard: Paste Center`).
- **v1.0.8**: Полноценные микро-панели с поддержкой двух режимов (хоткеи Actions / закрепление Dock).
- **v1.0.9**: Переименование панелей в `CP_copy` (иконка `CC`), `CP_paste` (иконка `CPA`), `CP_place` (иконка `CPL`). Крупные функциональные кнопки в интерфейсе, живая строка статуса.
- **v1.0.10**: Перевод всех панелей на единый общий движок ExtendScript `CP_SHARED` (`#targetengine "CP_SHARED"` и `<ScriptPath Engine="CP_SHARED">`) для гарантированного разделения буфера между панелями `CP_copy`, `CP_place` и `CP_paste`. Тройное резервирование в `$.global` и `app.__CP_BUFFER__`.
- **v1.0.11**: Устранение синтаксической ошибки ExtendScript (`ERR: No matching closing brace found`), удаление проблемной обёртки вокруг `$.global.ClipboardPasteHost`. Безопасная обработка ответов ExtendScript в CEP перед вызовом `JSON.parse()`.
- **v1.0.12**: Лаконичный компактный интерфейс главной панели: удалены неработающие бейджи хоткеев, убраны иконки и эмодзи из кнопок, убраны цифры 1/2/3 во вкладке списков. Создан общий модуль локализации `js/locales.js` на 8 языков с синхронизацией в реальном времени со всеми микро-панелями (`CP_copy`, `CP_place`, `CP_paste`).
